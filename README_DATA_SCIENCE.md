## Rapor Icin Kisa Ozet

Veri bilimi katmani, multi-agent karar sisteminin sadece sabit kurallarla degil,
veriyle kalibre edilebilir bir yapida tasarlandigini gosterir. Sistem; finansal,
stratejik ve operasyonel sinyalleri ayirir, CEO/CFO/HR agent skorlarini bu
sinyallerle iliskilendirir ve gelecekte ML siniflandirma veya agent agirlik
kalibrasyonu ile gelistirilebilir.
